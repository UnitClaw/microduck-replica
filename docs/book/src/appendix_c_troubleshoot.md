# 附录C 故障排查手册

> 全书故障排查速查，按现象定位。每条给出最可能原因与对应章节。

## C.1 仿真侧故障

| 现象 | 可能原因 | 处理 | 章节 |
|---|---|---|---|
| 仿真崩溃/数值爆炸 | MJCF 单位错误 / 惯性非正定 | 检查单位、`validate_mjcf.py` | 第4章 |
| 启动即倒地 | 重心/惯性参数错误 | 复核 CAD→MJCF | 第4章 |
| 关节剧烈抖动 | BAM 参数不匹配 | 台架重标定 | 第10章 |
| CUDA 内存不足 | num_envs 过大 | 减小 num_envs | 第9章 |
| 训练不收敛 | 奖励稀疏 / 学习率不当 | 调奖励、降学习率 | 第12章 |
| 动作发散 | 缺动作/平滑惩罚 | 加 penalty | 第12章 |

## C.2 真机侧故障

| 现象 | 可能原因 | 处理 | 章节 |
|---|---|---|---|
| 某舵机无响应 | ID 冲突 | 重配 ID | 第6章 |
| 总线随机丢包 | 信号干扰 | 降波特率、加隔离 | 第6章 |
| 上电卡死 | 供电不足/短路 | 分离供电、逐颗排查 | 第6章 |
| 位置漂移 | 供电电压跌落 | 检查 BMS、线径 | 第6章 |
| 步态抖动 | BAM 不准/控制环超时 | 重标定/优化推理 | 第10、14章 |
| 姿态慢慢歪 | IMU 零偏/安装倾角 | 六面校准/补倾角 | 第8章 |
| 经常摔倒 | 观测缩放错位 | `check_obs_act_space.py` | 第7、14章 |

## C.3 Sim2Real 差异排查（优先级）

| 优先级 | 检查项 | 工具 |
|---|---|---|
| 1 | 观测空间一致性 | `check_obs_act_space.py` |
| 2 | 关节限位对齐 | MJCF vs 硬件 |
| 3 | IMU 零偏/安装 | 六面校准 |
| 4 | BAM 参数精度 | 台架拟合 |
| 5 | 整机质量/重心 | 称重对比 CAD |

> 原则：**一次只改一个变量**，每次记录结果，避免多因素同时改导致无法定位。

## C.4 机械侧故障

| 现象 | 可能原因 | 处理 | 章节 |
|---|---|---|---|
| 舵盘打滑 | 过盈不足 | 换舵盘/加胶 | 第5章 |
| 关节卡死 | 打印干涉 | 修正 CAD 间隙 | 第3章 |
| 重心偏移 | 装配不对称 | 检查左右一致性 | 第5章 |
| 打印件断裂 | 壁厚/填充不足 | 加厚、提高填充 | 第5章 |
