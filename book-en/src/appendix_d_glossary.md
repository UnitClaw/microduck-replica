# Appendix D — Glossary

| Term | Full name / explanation | Chapter |
|---|---|---|
| Sim2Real | Simulation-to-Real transfer, the core paradigm | throughout |
| BAM | Bandwidth-Aware Motor, a bandwidth-aware servo actuator model | Ch. 10 |
| MJCF | MuJoCo robot-modeling file format | Ch. 4 |
| PPO | Proximal Policy Optimization algorithm | Ch. 12 |
| Domain Randomization | randomly perturbing simulation parameters during training | Ch. 11 |
| Curriculum Learning | progressing training from easy to hard | Ch. 11 |
| ONNX | Open Neural Network Exchange, a model-interchange format | Ch. 12, 14 |
| MuJoCo-Warp | NVIDIA GPU-parallel physics simulation | Ch. 9 |
| mjlab | Pollen's in-house robotics simulation library | Ch. 9 |
| TTL bus | half-duplex serial communication bus (used by servos) | Ch. 6 |
| Backlash | hysteresis caused by gear clearance | Ch. 10 |
| Randomization intensity | the range of the randomly perturbed parameters | Ch. 11 |
| Sim2Real gap | the dynamics gap between simulation and reality | Ch. 13, 15 |
| System identification | inversely identifying true parameters | Ch. 15 |
| RKNN | RK-platform neural-network inference toolkit | Ch. 7, 14 |
| BMS | Battery Management System | Ch. 6 |
| onshape-to-robot | CAD→MJCF automatic export tool | Ch. 4 |
| Observation space | the sensor-data vector fed to the policy | Ch. 9, 12 |
| Action space | the control-command vector output by the policy | Ch. 9, 12 |
